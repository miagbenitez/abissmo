# ABISSMO

Landing interactiva para una expedición ficticia por las especies marinas más peligrosas.

## Uso

Abrí `index.html` en un navegador moderno. El sitio es estático y no requiere instalar dependencias.

## Interacciones

- Recorrer la zona fótica, la zona de penumbra y el abismo con escenas, luz y color propios.
- Ver cómo las criaturas y los paisajes se mueven suavemente con las corrientes al aparecer en pantalla.
- Observar burbujas, sedimento y plancton bioluminiscente en las escenas submarinas.
- Activar el modo inmersión para escuchar un ambiente submarino suave; el sonido empieza solo al pulsar el botón.
- Encender la linterna y mover el cursor o el dedo para revelar el entorno submarino.
- Seguir la profundidad del descenso y saltar directamente entre zonas desde el indicador.
- Responder mini desafíos en cada zona para descubrir datos sobre la luz y la vida en las profundidades.
- Explorar los biomas de arrecife, aguas abiertas y zona abisal y filtrar las especies por hábitat.
- Explorar el mapa abisal por océano para encontrar las especies registradas en cada zona.
- Filtrar el registro por depredadores, especies venenosas o habitantes abisales.
- Buscar por nombre, nombre científico o hábitat; también se puede enfocar el buscador con `/`.
- Abrir las fichas de especie para ver sus datos y advertencias.
- Consultar tamaño, longevidad, alimentación y el índice editorial de peligro potencial de cada especie.
- Consultar las amenazas de conservación, las diferencias entre evidencia poblacional y presión sobre el hábitat, y las fuentes científicas enlazadas para cada especie.
- Lanzar un encuentro sorpresa para abrir la ficha de una especie al azar entre los resultados filtrados.
- Comparar dos especies elegidas entre sí por hábitat, profundidad, tamaño, longevidad, alimentación, amenaza y peligro.
- Guardar una bitácora local de las zonas y biomas recorridos y las fichas de especie descubiertas.
- Ver la cámara de expedición con encuadre, señal y cambios de luz animados.
- Escuchar grabaciones reales de camarones pistola, ambiente marino y ballena jorobada, con sus fuentes y créditos.
- Activar el modo inmersión desde el encabezado.

Las fotografías de tiburón y expedición se sirven desde Unsplash. Las imágenes de medusa caja, pulpo de anillos azules y pez rape se sirven desde Wikimedia Commons; sus autores y licencias están enlazados en el pie de página.
